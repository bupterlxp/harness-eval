## 关键设计决策摘要

1. **状态机设计**：使用显式枚举状态机而非 `while True + if` 链，符合正式规范
2. **工具分离**：将通用工具和领域特定工具分离，提高可扩展性
3. **上下文管理**：实现了源码缓存和上下文压缩，适合 LLM 处理
4. **快照机制**：每次修改前创建快照，支持原子回滚
5. **轨迹记录**：全流程 JSONL 记录，支持可追溯性
6. **LLM 集成**：支持 OpenAI 兼容接口，用于自动化 bug 分析
